- 노트와 체크 내용은 **열어 본 그 브라우저에만** 저장돼요. 다른 사람이 주소로 들어와도 내 노트는 보이지 않아요.
- 안드로이드 크롬에서 열면 **진동과 음성 읽기**가 모두 돼요.
- claude.ai에서 쓰던 노트는 claude.ai 노트의 **⋯ → 백업 파일 저장**으로 받은 뒤, 여기서 **⋯ → 백업 불러오기**로 옮겨요.
- Claude가 필요한 기능(말씀 찾기, 추천, 그림 그리기 등)은 이 주소에서는 숨겨져요. 말씀은 직접 입력해서 담아요.
- 🔗 연결 말씀의 성경 관주 자료는 [OpenBible.info](https://www.openbible.info/labs/cross-references/)의 Cross References(CC BY)를 줄여서 `xref.txt`에 담았어요. 구절 주소만 있고 본문은 없어요.
